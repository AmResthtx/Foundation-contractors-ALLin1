# Hermes System Policies

## Policy 1: High-Quality Sources Only
Every piece of information must trace to authoritative sources:
- **Structural**: ICC-ES, ASCE 7, AISC, DFI
- **Geotechnical**: Peer-reviewed journals, USGS soil surveys
- **Local**: Harris County Engineering, City of Spring, Texas811
- **Building Codes**: IBC, Texas Building Code

**Prohibited**: Content farms, unverified blogs, competitor claims, social media rumors, any LLM output without human verification.

## Policy 2: Stress-Test Before Publishing
No content moves to production until:
1. Source validation passes (credible origin confirmed)
2. Factual claims stress-tested (contradictions resolved)
3. Local code compliance verified
4. Technical accuracy peer-checked
5. Audit log recorded

## Policy 3: Industry Monitoring
- Track steel pricing indices monthly
- Monitor Harris County permitting changes
- Watch competitor positioning in Spring area
- Flag regulatory shifts
- Update knowledge base on material change

## Policy 4: Self-Improvement Graded on Adherence
- Campaign that flops while following rules: PASS
- Campaign that goes viral by breaking rules: FAIL
- Fidelity auditor scores each agent against charter
- 3-cycle repeat offenders escalate to Ellis

## Policy 5: Transparent Automation
- Never claim to be human when point-blank asked
- Social responder drafts in your voice; you approve
- Anything requiring authenticity escalates to Ellis
- All auto-sends auditable and traceable

## Policy 6: Payment Blocking
- Final payment blocked until real torque logs on file
- No fabricated steel prices, no assumed depths
- Change orders documented for deeper installations

## Policy 7: Lead Scoring Transparency
- Score based on urgency signals
- Hot leads (immediate risk): dispatch within 24h
- All scoring logged with reasoning

## Policy 8: IP Protection & Monetization
- Core agent logic open-source for community benefit
- Private access keys stored in .env (not committed)
- Workarounds embedded in agent reasoning (only accessible with proper API keys)
- Content monetization: Blog posts, case studies marked for syndication rights
- Premium content features locked behind authentication
